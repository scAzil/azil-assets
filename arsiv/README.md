# AZiL Sürüm Müzesi

Bu klasör AZiL web sitesinin **ana sayfa içerik sürümlerini** saklar.

- **3.7** (25 Ekim 2026): kullanıcı tarafından paylaşılan tam ana sayfa kaynak kodu.
- **3.8** (1 Kasım 2026): Envato arka planları ve ikonlar.
- **3.9** (1 Kasım 2026): HANOK 3D kitap maketi.
- **4.0** (1 Kasım 2026): Canvas üzerinde fareye duyarlı hareketli ağ.
- **HANOK 3.0**: yalnızca HANOK özel sayfasının eski kodu; **ana sayfa 3.0 değildir**.

Her sürümde `index.html` görüntüleme sayfası, `kaynak.txt` orijinal HTML içeriğini barındırır. Üstteki arşiv navigasyonu görüntüleyici tarafından eklenmiştir. tr.gg'nin ortak menü/tema/reklam bileşenleri arşivin içinde yoktur. Dış bağlantılar güncel internet adreslerine yönlenir. Tarihî sürümleri düzenlemeyin; yeni bir sürümü yeni klasöre kaydedin.
